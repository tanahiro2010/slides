## 記号の使い分け

## 「一言」の書き方

`article.md` の冒頭に置く引用。**反転を 1〜2 文で言い切る。**
説明しない。結論だけ置いて、本文で回収する。

既存の実例。

```
> 実装は、ちゃんと動きました。壊れていたのはドキュメントの方です。
> 「ゾーンはありません」。実際には 3 つありました。
> 「PHP コアの UAF で RCE」――その公開 PoC は私のラボでは動きませんでした。
```

共通しているのは次の 3 つ。

- **思っていたこと → 実際はこうだった**の形
- 具体物が入る（数、固有名、引用）
- 前置きが無い。1 文目から結論

| 記号 | 意味 |
| --- | --- |
| `🔥` | 山場。1 つのドラフトに 1〜3 個 |
| `✅` | 実測で確認済み |
| `📌` | 補足。見落としやすい点 |
| `📋 メモ⑬` | 末尾のメモ節への参照 |
| `§7` | 節への参照 |
| `❌` / `⭕` | 表現のルールの言い換え |

**記号を増やさない。** 意味が決まっているものだけ使う。

## 節の分量

1 節 15〜45 行。超えるなら割る。

| 節 | 目安 |
| --- | --- |
| 前提の整理 | 10〜20 行 |
| 実測を出す節 | 15〜30 行。表 1 つ + そこから言えること |
| 山場 | 20〜45 行。経緯まで書く |
| まとめ | 10〜20 行 |
