最近、クラシックを聴いている

  • 毎日聴いている
  • 音楽だけではなく
  • 所作まで優雅になりたい

目指せ、優雅の化身

  • 紅茶をこぼしても動じない
  • 想定外の連絡にも丁寧に返す
  • そして、たぶん無理

ところで、優雅とは？

  • 余裕
  • 判断
  • 配慮
  • ゆっくり動くことだけではなさそう

人生、予想外が多すぎる

  • 予定変更
  • 通信障害
  • 発表直前のトラブル

Graceful Degradation

  • 一部が壊れても
  • 本質的な機能を残す
  • 可能な状態で続ける

例外を正常系に

  • Unexpected Event → Panic → Crash
  • Unexpected Event → Understand → Adapt
  • そして、Respond

ElegantPerson.ts

interface ElegantPerson {
  composure: boolean
  consideration: boolean
  adaptability: boolean
}

function handle(event: UnexpectedEvent) {
  try {
    return respondElegantly(event)
  } catch {
    return respondWithDignity()
  }
}

残念ながら、ビルドが通らない

  • UnexpectedEvent が未定義
  • respondElegantly も未実装
  • 現実の私は、まだ開発中

優雅さ＝余裕の設計

  • 完璧に振る舞うことではない
  • 失敗時にも本質を守ること
  • 周囲に選択肢を返すこと

余裕を、他人に分けられる人へ

  • いま何が起きているかを伝える
  • 次に何をするかを伝える
  • 自分と周囲の余裕を残す

それでは、優雅な人生を

  • 想定外はなくせない
  • 代替経路は用意できる
  • まずは紅茶の淹れ方から

Stay Graceful.
