## 例外を正常系に

- Unexpected Event → Panic → Crash
- Unexpected Event → Understand → Adapt
- そして、Respond

::note::

- [30秒]
  - 左は、想定外が起きてパニックになり、停止する流れ
  - 右は、理解する → 適応する → 応答する流れ
  - 我慢して平静を装う、という話ではない
  - 次に可能な行動を残しておく、という話

---

## ElegantPerson.ts

```ts
interface ElegantPerson {
  composure: boolean
  consideration: boolean
  adaptability: boolean
}

function handle(event: UnexpectedEvent) {
  try {
    return respondElegantly(event)
  } catch {
    return respondWithDignity()
  }
}
```

::note::

- [35秒]
  - 人間の振る舞いをTypeScriptのインターフェースにしてみる
  - `composure` = 余裕
  - `consideration` = 配慮
  - `adaptability` = 状況への適応
  - `try/catch` = 最初の応答に失敗したときのフォールバック
  - `respondWithDignity()` は、尊厳を保った別の応答のつもり
